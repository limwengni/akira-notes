## Learning Schedule

Don't try to do all three 5-day plans at the same time. That will become messy fast.

**Sequential (recommended):**
- Week 1: LeetCode
- Week 2: Ruby/Rails
- Week 3: Web3

**Or if you really want all three daily:**
- 45 min LeetCode
- 45 min Ruby/Rails or Web3
- 10 min write notes
